Your rules, on every commit your agent makes.

Reviewers turns the things you keep telling your coding agent into checks it can't skip. A broken rule stops the commit, and the agent fixes it before you ever see it.

$ curl -fsSL https://reviewers.sh/install | sh

v0.1.0 · 6.2 MB · macOS and Linux · experimental

A commit, judged

Every Reviewer that applies runs at once, each as its own read-only Claude Code session. When one blocks, the agent gets the file, the lines and the fix.

Where the rules come from

The first run reads 90 days of your Claude Code sessions. Every correction you kept repeating becomes a Reviewer, with your own words kept as evidence.

$ reviewers

  • why is this called usr? spell it out→● Spell out names
  • never show error.message to the user, map it to copy→● Errors reach users through the error map
  • stop casting the API response, validate it→● No type casts
