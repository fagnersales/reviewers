reviewers is a commit gate for coding agents, written in Rust. Each Reviewer is one rule you hold about code, judged on every commit by its own read-only Claude Code session.

When a rule is broken, the commit stops and the agent gets the file, the lines and what to do instead. It fixes the code and commits again, without you.

The first run reads your Claude Code sessions, finds the rules you keep repeating to your agents, and turns them into Reviewers.

It runs on your own Claude Code, keeps everything on your machine, and is a single 5.87 MiB binary.

* * *

Rules you already hold

The first run reads 90 days of your sessions in parallel and turns your corrections into Reviewers, with your own words as evidence.

Every Reviewer at once

The Reviewers that apply to a commit run in parallel. A commit waits for the slowest one, not for all of them in a row.

Written for the agent

A block names the file, the lines and the fix, so the agent that made the commit can correct it on its own.

Personal and project rules

Some rules follow you into every repo, others belong to one codebase. Scope a Reviewer to paths and it only runs when they change.

Tested like code

Pin real diffs as cases and run reviewers eval until the instruction judges them right. Every version keeps its score.

Measured

reviewers stats shows what each Reviewer catches, the wait it adds and the tokens it uses, so you can retire the ones that never block.

Agents know how to use it

The installer gives Claude Code, Codex, Cursor and OpenCode a skill that points to reviewers help --agent, which updates with every release.

Tiny native binary

One 5.87 MiB binary that starts in 3 ms. No server, no background process.
